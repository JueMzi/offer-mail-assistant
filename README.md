# 秋招邮件助手

秋招邮件助手会以 **只读 IMAP** 方式读取招聘邮箱，整理投递进度、笔试/面试通知和截止日期，生成清晰的投递看板与日历。

## 开始使用

1. 下载同目录的exe文件。
2. 双击运行，无需安装 Python、Docker 或其他运行环境。
3. 程序会自动打开浏览器页面，并在 Windows 系统托盘驻留。
4. 点击右上角“设置”，填写邮箱配置后即可使用。

> 若 Windows SmartScreen 显示“未知发布者”，请确认文件来自本 Release，并核对 SHA-256 后，再选择是否继续运行。

## 首次配置邮箱

在“设置 → 邮箱配置”中：

1. 填写邮箱地址，常见邮箱的 IMAP 服务器会自动补全。
2. 在邮箱网页版开启 IMAP/SMTP，并获取 **客户端授权码**。
3. 将授权码填入“IMAP 授权码”。它不是邮箱登录密码。
4. 点击“测试连接”，成功后点击“保存”。
5. 返回首页，点击左上角“同步”开始第一次读取。

首次同步会读取并解析历史邮件，邮件较多时可能需要几分钟；完成后刷新页面即可查看新增的投递记录和日程。

## 主要功能

- 只读同步招聘邮箱，支持手动同步与定时同步
- 自动识别公司、岗位、投递阶段、笔试/面试和截止日期
- 投递看板：管理进行中、泡池、已 OC、已放弃和未通过等状态
- 月视图与周视图日历、未来日程和未完成提醒
- 邮件详情、链接直达、回收站与操作日志
- 可选 AI 识别：不配置 AI 也能使用本地规则完成基础识别

## 数据与隐私

- 程序通过 IMAP **只读**访问邮箱，不会发送、删除或修改邮件。
- 邮箱授权码、AI 配置和个人数据只保存在本机：

  ```text
  %LOCALAPPDATA%\秋招邮件助手\data
  ```

- 升级或替换 EXE 不会清除上述数据。
- 如启用 AI 识别，相关邮件内容会发送到你在设置中填写的 AI 服务接口进行解析；请根据自己的隐私要求决定是否启用。

## 使用说明

- 程序运行后会显示在系统托盘；右键图标可“打开页面”或“退出”。
- 如浏览器没有自动打开，可通过托盘菜单选择“打开页面”。
- 默认本机地址为 `http://127.0.0.1:6868`，仅本机可访问。
- 若无法启动，可能是 6868 端口被占用；请关闭占用该端口的程序后重试。

## 更新版本

1. 在系统托盘右键秋招邮件助手，选择“退出”。
2. 下载新版 `秋招邮件助手.exe` 并替换旧文件。
3. 双击新版 EXE 启动；已有配置和数据会继续保留。
