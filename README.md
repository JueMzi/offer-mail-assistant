# 秋招邮件助手

> 把招聘邮箱中的投递、测评、笔试、面试与 Offer 通知，整理为本地投递看板和日历。

![秋招邮件助手封面](readme-hero.png)

秋招邮件助手是一个 Windows 本地桌面工具。它通过 **只读 IMAP** 读取指定邮箱中的招聘邮件，自动归并同一岗位的多封通知，并在浏览器中提供投递状态表、日历、待办、邮件详情和操作日志。


## 它能做什么

- **读取招聘邮件**：支持手动同步、定时同步和重新扫描当前范围；邮件通过 IMAP 只读访问，不会发信、删信或标记已读。
- **整理投递进度**：自动识别公司、岗位、投递、测评/AI 面、笔试、面试、Offer 与未通过等状态，并合并同一岗位的多封邮件。
- **生成日程与提醒**：从测评、笔试、面试和有效期通知中提取时间，生成日历与待办提醒。
- **保留邮件上下文**：每条自动记录可查看关联邮件正文和原始链接，方便核对识别结果。
- **允许人工接管**：可以手动新增或编辑投递和日程；已手动修改的邮件记录不会被 AI 历史校正覆盖。
- **可选 AI 增强**：未配置 AI 时仍可用关键词和规则完成基础识别；配置 OpenAI 兼容 API 后，可提高公司、岗位和时间识别准确性。

## 快速开始

1. 下载并双击 `offer-mail-assistant-v1.0.x.exe`。
2. 程序会启动本地服务、自动打开浏览器，并驻留在 Windows 系统托盘。
3. 在页面右上角打开 **设置 → 邮箱配置**，填写邮箱地址、IMAP 授权码和服务器地址。
4. 点击 **测试连接**；通过后点击 **保存**。
5. 回到首页点击 **同步邮箱**，等待首次整理完成。

默认访问地址为 [http://127.0.0.1:6868](http://127.0.0.1:6868)，只允许当前电脑访问。

## 配置邮箱

程序使用 IMAP 协议，通常需要在邮箱网页版完成以下操作：

1. 开启 IMAP 服务；
2. 创建或获取 **客户端授权码**；
3. 在程序中填写邮箱地址和授权码。

授权码不是邮箱登录密码。常见邮箱会自动补全 IMAP 服务器；若未自动补全，请从邮箱官方帮助页面查询主机和端口。程序默认以 SSL 方式连接 IMAP 993 端口。

## 三种邮件处理方式

| 操作 | 适用场景 | 处理范围 |
| --- | --- | --- |
| 首页“同步邮箱” | 日常使用 | 获取最近 30 天内的新邮件，仅处理此前未识别的邮件。 |
| “重新扫描当前范围” | 规则升级后补漏、重新归并历史记录 | 重新读取设置中的同步范围内邮件。 |
| “使用 AI 校正历史数据” | 之前未配置 AI，或识别规则更新后 | 不连接邮箱，重新处理本机已保存的自动识别记录。 |

每次同步或重新扫描最多获取 **500 封最新邮件**。同步范围可在设置中选择最近 7、30、90、180 或 365 天；定时同步使用该设置范围。

AI 校正只处理“邮件自动识别”且未被手动编辑接管的记录。手动新增和已手动修改的记录不会被处理或修改。

## 使用提示

- **同步任务互斥**：同步邮箱、重新扫描和 AI 校正一次只能执行一项；若已有任务进行中，请在完成后再执行下一项。
- **首次同步耗时**：邮件较多或启用 AI 时，首次同步可能需要数分钟。完成后看板会自动刷新。
- **人工修改优先**：对自动记录做过手动编辑后，AI 历史校正会跳过它；如需恢复自动判断，请按实际情况手动调整状态。
- **未通过识别**：仅明确的淘汰、岗位/应聘结束或笔试、测评、面试取消通知会识别为未通过；“若未通过”“违规将取消资格”等条件说明和链接不会被当作当前结果。
- **重新扫描不重复建档**：已有投递和日程会自动归并，避免重复创建。

## AI 配置（可选）

在 **设置 → AI 配置** 中填写 OpenAI 兼容接口的 API Key、接口地址和模型名称即可启用 AI。适用于 DeepSeek 或其他兼容 Chat Completions 的服务。

- 未配置 AI：使用本地关键词、正则和时间规则；
- 配置 AI：在候选邮件基础上增强公司、岗位、阶段、摘要和日程提取；
- AI 解析结果会保存在本机缓存中，重复处理相同邮件不会重复请求。

启用 AI 时，候选招聘邮件内容会发送到你填写的 AI 服务商接口，请根据自己的隐私要求决定是否开启。

## 数据与隐私

- 邮件通过 IMAP **只读**访问：程序不会发送、删除、移动、标记或修改邮箱中的邮件。
- 邮箱授权码、AI 配置、投递、日程、邮件详情、缓存与日志均保存在当前 Windows 用户本机：

  ```text
  %LOCALAPPDATA%\秋招邮件助手\data
  ```

- 替换或升级 EXE 不会清除上述数据。建议定期备份该文件夹。
- 托盘菜单可打开页面、退出程序，并可设置当前 Windows 用户开机自启动。

## 常见问题

### 浏览器没有自动打开怎么办？

在系统托盘中找到“秋招邮件助手”图标，右键选择“打开页面”；也可以手动访问 [http://127.0.0.1:6868](http://127.0.0.1:6868)。

### 程序无法启动或页面无法访问？

默认端口为 `6868`。请检查是否有其他程序占用了该端口，退出冲突程序后再启动本工具。

### 为什么没有识别到某封历史邮件？

先确认邮件在当前同步范围内，然后使用 **重新扫描当前范围**。若此前未配置 AI，或最近更新过识别规则，可再使用 **AI 校正历史数据**。

### 如何更新到新版？

1. 在系统托盘右键程序图标，选择“退出”；
2. 下载新版 EXE 并替换旧文件；
3. 双击新 EXE 启动。

本地配置与数据会继续保留。
